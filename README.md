# 🪐 Cosmos Explorer 3D

An interactive, full-screen 3D tour of the Solar System and beyond — built with plain HTML, JavaScript and [three.js](https://threejs.org/). No build step, no installation: it is a single `index.html` file.

**Live demo:** `https://YOUR-USERNAME.github.io/cosmos-explorer/` *(after you enable GitHub Pages)*

## Features

- **Solar System:** the Sun, 8 planets, Pluto, moons, Saturn's rings and orbits. Click any name to fly to it and read facts.
- **Zoom out:** scroll to leave the Solar System and reach the Milky Way, the Local Group, the Virgo Cluster and distant galaxies.
- **Interior layers:** cutaway views of the Sun, planets and moons (core, mantle, atmosphere…).
- **Surface & atmosphere:** real map-based surface view, atmosphere layers and data; add your own real surface photo/panorama.
- **Asteroids & meteoroids:** Ceres, Vesta, Eros, Bennu, Apophis…, a rock-filled asteroid belt and a meteor shower over Earth.
- **Presentation mode:** 12 transparent slides over the live 3D scene, each with 3D camera motion and video links (you can also attach your own video).
- **Animations:** black hole event horizon, light travel (Sun → Earth in 8 min 20 s, slow motion), "Where do we live?" zoom-out from Earth to the observable universe, Kalpana Chawla tribute and Columbia re-entry.
- **Music:** an original generated ambient track (or load your own audio file).

## Run it

- **Locally:** download `index.html` and double-click it (needs an internet connection to load three.js from a CDN).
- **Online:** GitHub Pages — see below.

## Controls

Drag = rotate · Scroll / pinch = zoom · Click a label = explore · Esc = close any panel.

## Deploy with GitHub Pages

Repository → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → **Save**.
